**Proyecto Pilates Barbate**

He desarrollado una página web para el estudio Pilates Barbate, diseñada para mostrar sus servicios, bonos, instalaciones, filosofía de trabajo y formas de contacto.

La web ha sido creada con una estructura clara, moderna y responsive, adaptada a todo tipo de dispositivos. También se ha incorporado un sistema de traducción al inglés, optimización SEO y diferentes llamadas a la acción para facilitar el contacto mediante teléfono, WhatsApp, correo electrónico e Instagram.

Durante el desarrollo, se ha trabajado especialmente en la presentación visual del estudio, la galería de imágenes, la accesibilidad y la optimización de la experiencia de usuario.

## Objetivo

Este proyecto consiste en el desarrollo de una página web estática para Pilates Barbate, un estudio especializado en clases de Pilates, entrenamiento personalizado y bienestar.

La plataforma permite presentar los diferentes bonos y modalidades de clase, mostrar el espacio y sus instalaciones, ofrecer información sobre el equipo, facilitar la localización del estudio e incluir diferentes vías de contacto para potenciales clientes.

Además, la web cuenta con optimización para buscadores, datos estructurados, sitemap, archivo `robots.txt`, etiquetas Open Graph y diseño responsive para mejorar su visibilidad y accesibilidad.
