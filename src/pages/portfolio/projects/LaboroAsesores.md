**Proyecto Laboro Asesores** He desarrollado una página web basada en un estudio previo de SEO, con el objetivo de aumentar la visibilidad del negocio y mejorar su alcance dentro de la provincia del cliente. Toda la estructura, contenidos y optimización de la web se han adaptado estratégicamente a sus objetivos comerciales, enfocándose en atraer tráfico local cualificado y mejorar el posicionamiento en buscadores.

Durante todo el proceso, he trabajado mano a mano con el cliente, realizando ajustes continuos en diseño, contenido y funcionalidad hasta conseguir un resultado final completamente alineado con sus expectativas y necesidades.

## Tecnologías

- React
- Node.js
- JavaScript
- Vite
- Css
- HTML
- Git Hub/Git

## Objetivo

Este proyecto consiste en el desarrollo de una aplicación web Full Stack para la empresa Laboro Asesores, orientada a servicios de asesoría, mentoría y gestión de asuntos relacionados con el ámbito jurídico y legal.

La plataforma ha sido diseñada para ofrecer una experiencia clara, profesional y accesible, facilitando la comunicación entre la empresa y sus clientes, así como la consulta de información y servicios de forma estructurada y eficiente.
