**Proyecto Fiscal IA**

He desarrollado un prototipo de asistente de voz basado en inteligencia artificial capaz de interactuar con el usuario mediante voz y automatizar el proceso de reserva de citas para una asesoría fiscal.

El sistema permite al usuario iniciar una conversación mediante el micrófono, proporcionar sus datos, indicar el motivo de la consulta y solicitar una fecha para la cita. La aplicación interpreta la información, consulta las horas disponibles y confirma la reserva mediante una conversación guiada.

Además, el sistema incorpora síntesis de voz mediante Piper TTS, reconocimiento de voz mediante la Web Speech API, un historial de conversación, estados visuales de la IA y generación automática de un recordatorio de la cita en formato JPG.

## Objetivo

El objetivo del proyecto es crear una experiencia de reserva de citas completamente interactiva mediante voz, simulando el funcionamiento de una recepcionista virtual para una asesoría fiscal.

Durante el desarrollo he trabajado en un flujo completo de interacción por voz: captura de la voz del usuario, conversión a texto, interpretación de la información, gestión de fechas y horarios disponibles, generación de respuestas mediante síntesis de voz y confirmación final de la cita.

La aplicación está desarrollada con React y TypeScript para gestionar la interfaz, los estados de la conversación y el historial de mensajes. Node.js se utiliza para gestionar la comunicación con el sistema de generación de audio, mientras que Python y Piper TTS permiten generar voz en español de forma local.

También he desarrollado una interfaz responsive adaptada a escritorio y dispositivos móviles, incorporando diferentes estados visuales para representar cuándo la IA está escuchando, procesando información o respondiendo.

## Funcionalidades

- Conversación mediante voz.
- Reconocimiento de voz mediante Web Speech API.
- Síntesis de voz en español mediante Piper TTS.
- Recopilación de nombre, teléfono y motivo de la consulta.
- Selección de fechas para la cita.
- Consulta de disponibilidad horaria.
- Confirmación de citas mediante conversación.
- Historial de mensajes actualizado en tiempo real.
- Indicadores visuales del estado de la IA.
- Interfaz responsive para escritorio y móvil.
- Generación automática de recordatorios.
- Exportación del recordatorio en formato JPG.
- Procesamiento local de la síntesis de voz sin API key.
- Backend local desarrollado con Node.js.
- Integración entre React, Node.js y Python.
